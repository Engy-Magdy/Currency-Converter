# 💱 Currency Converter

A clean and interactive command-line currency converter built in Python, focusing on smart logic, structured design, and an engaging user experience. 💡

---

## 💎 Features

* **💵 Interactive UI:** Features a custom ASCII art banknote interface for an engaging terminal experience.
* **⏳ Smart UX Design:** Implements deliberate pacing and loading states to simulate real-time market data processing (Labor Illusion).
* **⚙️ Modular Code:** Built using Python functions and data dictionaries for clean organization and easy scalability.
* **🛡️ Flow Control:** Includes confirmation steps and validation checks to ensure smooth navigation and error handling.
